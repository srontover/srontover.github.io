\section{科研经历}\color{black}
\cvproject{通过强化学习学习人形机器人的动态技能}{2026--至今}{T1 人形机器人踢球与运动控制}
\begin{itemize}
  \item 基于 MuJoCo/MJLab/Warp 仿真工具链，为人形机器人运动控制与接触丰富踢球任务实现并修改强化学习环境。
  \item 实现并评估动作与观测空间、球体重置逻辑、接触检测、奖励函数、终止条件以及课程学习等任务组件。
  \item 通过实验分析策略行为，包括接触质量、足球速度、目标方向误差、踢球后恢复能力和训练稳定性。
  \item 研究 Conditional AMP 和运动先验驱动的踢球策略，并探索不同球体位置和踢球方向条件下的技能泛化能力。
\end{itemize}

\cvproject{Conditional AMP 驱动的人形机器人泛化踢球学习}{2026}{强化学习研究项目}
\begin{itemize}
  \item 研究距离条件化 Conditional AMP 在人形机器人踢球任务中的应用，使用目标距离和踢法类型条件向量与课程学习。
  \item 研究 expert-policy 条件分布对齐与运动先验如何影响训练稳定性和跨条件技能泛化。
\end{itemize}

\cvproject{面向人形机器人技能获得的运动先验学习}{2026}{研究探索}
\begin{itemize}
  \item 调研 AMP 类运动先验、人体运动数据、encoder-decoder 策略以及 latent 表示在人形机器人技能学习中的应用。
  \item 探索任务奖励与运动先验奖励之间的平衡，以获得自然且有效的机器人行为。
\end{itemize}
